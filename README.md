# おきなわ行政お知らせ

沖縄県と県内41市町村のホームページに載る新着のお知らせを1ページにまとめるツールです。

## 使い方

1. `python fetch_news.py` を実行します。1分ほどで全42団体のお知らせを取得し、`index.html` を作り直します。
2. `index.html` をブラウザで開きます。キーワード、地域（県・北部・中部・南部・宮古・八重山）、市町村、期間で絞り込めます。前回開いたあとに増えたお知らせには「NEW」が付きます。

## 毎日自動で更新する

```
powershell -ExecutionPolicy Bypass -File register_task.ps1
```

Windows のタスクスケジューラに「OkinawaGovNews」として登録し、毎日7:00に実行します。時刻を変えるときは `-Time 06:30` を付けます。
指定した時刻に PC が起動していなかった場合は、次に起動したときに実行されます。
最後に実行したときの結果は `data/last_run.log` に残ります。

## ファイル

| ファイル | 内容 |
|---|---|
| `sources.json` | 取得元の一覧。URL が変わったときはここを直します |
| `fetch_news.py` | 取得とページ生成を行うスクリプト（標準ライブラリだけで動きます） |
| `template.html` | ページのひな形 |
| `index.html` | 生成されたページ |
| `data/items.json` | 取得済みのお知らせ。過去180日分を残します |
| `data/status.json` | 団体ごとの取得結果 |

## 取得元について

- 多くの団体は RSS / Atom を使います。
- 次の10市町村は、RSS の更新が止まっていたり件数が少なかったりするため、同じ CMS が公開している新着一覧 JSON（`index.update.json`）を使います：
  宜野湾市、豊見城市、石垣市、大宜味村、東村、今帰仁村、金武町、読谷村、北中城村、粟国村。渡嘉敷村と宜野座村は RSS が空なので、同じ JSON を使います。
- 多良間村には RSS がないため、サイト自身のお知らせ一覧 JSON を使います。
- 取得に失敗した団体は、ページ下の「取得状況」に赤字で出ます。
